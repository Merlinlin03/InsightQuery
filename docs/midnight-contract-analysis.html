1. 指标口径与方法说明
  • 市场口径：美国 = dim_user.market_id 关联 dim_market.country_code = 'US'，即用户注册市场口径；事实表 fact_episode_view 本身无 market 列。
  • 开播口径：fact_episode_view.started = 1，去重键 user_id，UTC 日历日聚合，周期为闭区间，每周期各 7 天、长度一致且均已完结。
  • 续看率口径：同周期、同剧、同 US 用户口径内按 user_id 匹配，续看率 = 第2集去重开播用户数 / 第1集去重开播用户数。本数据中第2集用户 100% 为第1集用户，故分子 = 第2集去重UU。
  • 对比方式：比率由汇总分子与分母重新计算（未对行级比率取平均）；加和指标报绝对变化量，比率指标同时报百分点差、相对变化率及分子分母样本量。
  • 分解方法：对 R = N/D 采用对称（中点）恒等分解，分子效应 = ΔN·½(1/D₁+1/D₂)，分母效应 = Δ(1/D)·½(N₁+N₂)；并用对称对数分解交叉验证份额。分解仅描述变化来源，不引入因果结论。
2. SQL 口径原文与查询结果（数据溯源）

数据源：Doris 只读库 insightquery_short_drama，事实表 fact_episode_view，维度表 dim_episode / dim_series / dim_user / dim_market。以下为本次分析所依据的查询口径原文与结果。

-- 目标库: insightquery_short_drama (Doris, 只读) · 维度映射
--   剧集 Midnight Contract -> dim_series.series_id = 1
--   第1集 -> dim_episode.episode_no = 1 (episode_id = 11)
--   第2集 -> dim_episode.episode_no = 2 (episode_id = 12)
--   美国市场 US -> dim_market.country_code = 'US' (market_id = 1)
--   开播 -> fact_episode_view.started = 1 ; 去重键 -> user_id
--   市场归属: 事实表无 market 列, 经 dim_user.market_id 归属用户注册市场
--   周期: P1 = 2026-09-01 ~ 2026-09-07 ; P2 = 2026-09-08 ~ 2026-09-14 (UTC 日历日, 闭区间)

-- Query 1: 两周期 x 第1/2集 开播去重用户数
SELECT
  CASE WHEN v.event_date BETWEEN '2026-09-01' AND '2026-09-07' THEN '2026-09-01~09-07'
       WHEN v.event_date BETWEEN '2026-09-08' AND '2026-09-14' THEN '2026-09-08~09-14' END AS period,
  e.episode_no, e.episode_id,
  COUNT(DISTINCT v.user_id) AS launch_uu
FROM fact_episode_view v
JOIN dim_episode e ON e.episode_id = v.episode_id
JOIN dim_user    u ON u.user_id    = v.user_id
JOIN dim_series  s ON s.series_id  = e.series_id
JOIN dim_market  m ON m.market_id  = u.market_id
WHERE v.started = 1 AND s.title = 'Midnight Contract' AND m.country_code = 'US'
  AND e.episode_no IN (1,2)
  AND v.event_date BETWEEN '2026-09-01' AND '2026-09-14'
GROUP BY period, e.episode_no, e.episode_id
ORDER BY period, e.episode_no;

-- Query 2: 次集续看率 = 同周期同剧同 US 用户内, 第2集去重用户 / 第1集去重用户
WITH us_views AS (
  SELECT v.user_id, e.episode_no,
         CASE WHEN v.event_date BETWEEN '2026-09-01' AND '2026-09-07' THEN 'P1_0901_0907'
              WHEN v.event_date BETWEEN '2026-09-08' AND '2026-09-14' THEN 'P2_0908_0914' END AS period
  FROM fact_episode_view v
  JOIN dim_episode e ON e.episode_id = v.episode_id
  JOIN dim_user    u ON u.user_id    = v.user_id
  JOIN dim_series  s ON s.series_id  = e.series_id
  JOIN dim_market  m ON m.market_id  = u.market_id
  WHERE v.started = 1 AND s.title = 'Midnight Contract' AND m.country_code = 'US'
    AND e.episode_no IN (1,2)
    AND v.event_date BETWEEN '2026-09-01' AND '2026-09-14'),

u1 AS (SELECT DISTINCT period, user_id FROM us_views WHERE episode_no = 1),

u2 AS (SELECT DISTINCT period, user_id FROM us_views WHERE episode_no = 2)

SELECT u1.period,
       COUNT(DISTINCT u1.user_id) AS ep1_uu,
       COUNT(DISTINCT u2.user_id) AS ep2_and_ep1_uu,
       ROUND(COUNT(DISTINCT u2.user_id) / COUNT(DISTINCT u1.user_id), 4) AS continuation_rate
FROM u1 LEFT JOIN u2 ON u1.user_id = u2.user_id AND u1.period = u2.period
GROUP BY u1.period ORDER BY u1.period;

-- Query 3 (异常检测): 第2集用户是否都曾看过第1集 -> ep2_uu=189, ep2_with_ep1=189, ep2_never_ep1=0

4. 数据质量提示与结论适用范围（限制）
  • 合成数据：本次数据为合成数据，结论不来自任何真实业务系统，仅用于展示分析口径与流程。
  • 两周期为互斥人群队列：第1集两周各 168 人但完全互斥（168+168=336 去重），第2集 126+63=189 去重。横向对比反映的是不同新触达人群的续看差异，不是同批用户的留存衰减，不可解读为"用户看下去意愿下降"。
  • 规模相同 ≠ 人群相同：仅知两周第1集人数相等，无法验证人群构成（来源、活跃度、偏好）是否同质。
  • 事件粒度限制：每用户每集在全区间仅 1 条播放事件（max_events_per_user_episode = 1），无法观察重复观看次数、观看进度与中断行为，因而"观看深度"类解释不可检验。
  • 维度不足：事实表无市场列、无内容来源/题材/设备字段，本次仅能下钻到"集数 × 周期"，无法拆分队列构成差异。
  • 无倒挂：第2集 189 名用户全部看过第1集（ep2_never_ep1 = 0），漏斗顺序自洽，未发现数据异常。
  • 续看为集合交集口径：续看率按同一周期内 user_id 集合交集计算，未校验第2集事件日期 ≥ 第1集事件日期的先后顺序（事实表仅日历日粒度，无事件时间戳）；本数据每用户每集全区间仅 1 条事件（max_events_per_user_episode = 1），该口径不改变任何数字，但在多事件数据上需补充先后顺序约束。
  • 季节性/结构因素：两周期均为各 7 天、起点同为周二，星期构成一致（09-01 与 09-08 均为周二起）；剧集上线日为 2026-09-01，即周期1 首日，不存在同剧预热期。
  • 统计推断：本次为全量口径（非抽样、非随机实验），不做假设检验；为便于量级参考，两队列续看率差的 95% 独立比例区间为 [-47.3 pp, -27.7 pp]（SE = 5.01 pp），该区间仅作效应量级参考，不作为推断结论。
  • 时间窗口：仅覆盖两周，无法判断该差异是持续趋势还是单周期波动；如需判断稳定性需扩展至更多周期。
5. 后续验证建议（按优先级）
  • 补充队列构成维度：在第1集用户上叠加注册来源、注册日期、设备或偏好标签，检查两周第1集人群是否同质；若构成差异显著，续看率差异需先做结构标准化后再比较。
  • 引入第2集曝光/付费墙数据：将"第2集开播UU"拆为"第1集完播 → 第2集曝光 → 第2集开播"，区分是引导曝光不足还是曝光后不点击。
  • 延长观察窗口：扩展到更多连续周，判断 37.5% 是单周波动还是水平位移；同时以滚动 7 天口径监测，避免跨周期切割造成人群边界偏移。
  • 监测指标：次集续看率（主）、第2集开播去重UU（分子）、第1集开播去重UU（分母，护栏，防止分母缩水伪装成比率改善）。
